# Rift Archive

Deutschsprachige League-of-Legends-Wiki mit Champion-Verzeichnis, Items, Rollen- und Spielwissen.

Die Web-App ist statisch und startet direkt über `index.html`. Champion- und Item-Daten stammen aus Riot Games Data Dragon.

## Start

Öffne `index.html` lokal oder hoste das Repository als statische Website über Vercel.

## Hinweis

Fan-Projekt, nicht von Riot Games unterstützt oder gesponsert.
